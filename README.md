# NailedIt

A browser-based thumbnail studio for creating polished YouTube, blog, Open Graph, and vertical social graphics directly in the browser.

## What it does

- Professional, aesthetic thumbnail templates
- YouTube, OG/blog, and Reels aspect ratios
- Custom title, subtitle, category, keywords, logo, and speaker imagery
- Scale and pan controls for visual positioning
- High-DPI Canvas rendering
- PNG and WebP export
- Clipboard image copy
- Client-side image processing for privacy and speed

## Tech Stack

React · TypeScript · Vite · Tailwind CSS · HTML5 Canvas · lucide-react

## Development

```bash
npm install
npm run dev
```

## AI Coding & Design Rules

AI agents working on NailedIt should treat the repository's visual quality and rendering architecture as first-class concerns. Preserve the existing component contracts, keep preview rendering fast, use deliberate composition and typography, handle asynchronous image rendering safely, and avoid turning templates into collections of arbitrary rectangles and magic numbers.

See the project history and source code for the current implementation; the actual repository is the source of truth.
